# Notion设计系统落地 - 简介与亮点

## 来源
Figma Config 2026：Everyone's still eating: building Notion's design system

## 一句话简介
Notion 设计系统团队分享如何在一个巨大且仍在高速运转的代码库里建立设计系统、迁移组件，并让人类和 AI agent 都遵守规则。

## 节目简介
这一集讲的是 Notion 设计系统从无到有的落地过程。讲者把迁移过程比作晚宴上“大家还在吃饭时抽掉桌布、同时铺上新桌布”：既要定义颜色、图标、组件和样式规则，又要迁移庞大的旧代码库，还要在 AI agent 大量写代码的时代，让正确路径变成最容易走的路径。

## 亮点
- 设计系统不只是组件库，而是一组关于产品灵魂和表达方式的共享决策。
- Notion 的问题不只是视觉不一致，还有开发体验差、组件混乱、代码依赖像“肉丸”一样纠缠。
- 机械迁移适合交给 agent，但精细判断仍需要人类设计品味和视觉验证。
- 文档、lint、ratcheting、PR blocker 形成从“可忽略”到“不可绕过”的规则谱系。
- 对 AI agent 来说，也要让正确路径成为最小阻力路径，否则它会绕过规则。

## 适合片头播报
这一集我们听 Notion 设计系统团队讲一个很真实的迁移故事：当产品已经很大、团队仍在高速开发、AI agent 也开始大量写代码时，设计系统该怎么落地？这不是一场只讲组件库的分享，而是关于共享决策、代码迁移、自动化验证，以及如何让人类和机器人都守住产品气质的经验复盘。
