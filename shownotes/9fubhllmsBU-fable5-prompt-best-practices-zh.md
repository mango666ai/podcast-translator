# Fable5 提示词最佳实践 - 简介与亮点

## 一句话简介
Anthropic Claude Code 团队成员分享如何理解 Fable 这类新模型，以及如何通过工具、上下文和更好的提问方式释放 Claude 的能力。

## 节目简介
这一集围绕 Anthropic 新模型 Fable 展开，讲者把它描述成“地图正在展开”的时刻：AI 不只是更会聊天，而是因为工具、代码执行、主动工作、HTML 报告等能力，开始以尖峰式方式变聪明。演讲重点不是简单罗列功能，而是讨论人应该如何和更强的模型协作：给 Claude 松绑，找出自己的未知，接受编程方式变化带来的失落感，并在 AI 时代变得更有野心。

## 亮点
- “能力悬置”：模型真正变强，往往不是靠记忆更多，而是因为工具让它能做以前做不到的事。
- 系统提示词也在演化：更强的新模型不一定需要更多示例，过多示例反而可能限制想象力。
- 与 Fable 协作时，人也要给自己松绑：提示词里的“地图”和真实代码库的“领土”并不一样。
- 用盲点扫描、访谈、参考代码和实现备注，帮助模型找出你没意识到的未知问题。
- AI 编程带来巨大的效率跃迁，也带来某种失落感；讲者的答案是“穿过去”，用更高野心做更好的工作。

## 适合片头播报
这一集我们听 Anthropic Claude Code 团队成员聊 Fable，以及更强模型出现后，人应该如何重新理解提示词、工具和协作方式。它不是一场普通的模型发布介绍，而更像一份和 AI 一起工作的野外指南：什么时候要给 Claude 松绑，怎么发现自己没说清楚的未知，以及为什么 AI 让我们可以少一点“合理”，多一点野心。
